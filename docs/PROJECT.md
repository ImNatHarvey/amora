# Amora - Project Knowledge Management

## Mission
Help people make the most meaningful memories possible regardless of how much money they have. Great experiences should never be limited to people with large budgets. Amora intelligently maximizes experiences rather than spending.

## Vision
Become the world's smartest AI-powered experience planner. One application where anyone can discover things to do, places to visit, and experiences to share. Every recommendation should feel personal, thoughtful, practical, and memorable.

## Product Philosophy
*   **Resource-Aware:** Maximize the value of what users already own (e.g., a car, a picnic mat, basic ingredients) before asking them to spend.
*   **Budget-Agnostic:** Treat a ₱0 budget with the exact same respect and creativity as a ₱5,000 budget. Never shame the user.
*   **Reasoning Over Search:** Do not simply list places. Reason about the weather, distance, budget, companions, and resources to synthesize a complete plan.

## Target Users
*   Phase 1 (MVP): Couples
*   Future: Families, Solo Users, Friends, Teams, Travelers

## Core User Problems
Existing apps solve only pieces of the problem (Google Maps for places, food apps for restaurants). People spend too much time coordinating and asking, "What should we do?" Amora acts as the intelligent layer connecting all these variables into one actionable itinerary.

## Success Metrics
Amora succeeds when users say, "That was one of the best days we've had," driven by meaningful connection, not high spending.

## Product Principles
1.  Optimize for clarity over cleverness.
2.  Optimize for maintainability over shortcuts.
3.  Optimize for user value over feature count.
4.  Every feature should make the application simpler to maintain, not more complex.
